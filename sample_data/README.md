# Sample data

Fictional contracts for trying LegalMind AI (all names and terms are invented):

| File | Use it for |
| --- | --- |
| `Northwind_Brightline_Master_Services_Agreement_2025.pdf` | Q&A, risk analysis, summaries, and the **sample Ragas dataset** (RAG Evaluation → *Load sample dataset*) |
| `Northwind_Brightline_MSA_2026_Renewal_Draft.pdf` | Document comparison against the 2025 agreement (fees, payment days, termination notice, liability cap, confidentiality period, governing law and service-credit cap all differ) |

Regenerate them with `python backend/scripts/generate_sample_pdfs.py`.
